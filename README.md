# todo-app

todo-app - это веб-сервер, который реализует функциональность планировщика задач (аналог TODO-листа).

----

Приложение хранит задачи, каждая из которых содержит дату дедлайна и заголовок с комментарием. Задачи могут повторяться по заданному правилу: например, ежегодно, через какое-то количество дней, в определённые дни месяца или недели. Если отметить такую задачу как выполненную, она переносится на следующую дату в соответствии с правилом. Обычные задачи при выполнении удаляются.

### Configurate

Для изменения конфигурации приложения задайте соответсвующие переменные окружения, например, с помощью команды `export`:

```bash
export TODO_PORT=7550
```

Список поддерживаемых параметров:

- `TODO_PORT` - определяет порт, на котором будет доступно приложение

- `TODO_DBFILE` - определяет расположение создаваемой/существующей базы данных, которая будет использована

- `TODO_PASSWORD` - если вы задали эту переменную, то приложение потребует аутентификации по этому паролю для его использования

## To start using todo-app using docker

### Default configuration (Stateless)

Для запуска приложения с помощью docker в первую очередь соберите docker-образ, подставив имя образа и его версию в следующую команду:

```bash
docker build -t ${IMAGE_NAME}:${IMAGE_TAG} .
```

Запуск контейнера в стандартной конфигурации без сохранения стейта:

```bash
docker run -p ${HOST_PORT}:7540 ${IMAGE_NAME}:${IMAGE_TAG}
```

После этого приложение будет доступно локально на порту -p 7540:7540:

```bash
curl localhost:7540
```

### Custom configuration

Для изменения конфигурации используйте флаги `--env` или `--env-file` при запуске контейнера:

```bash
docker run -p ${HOST_PORT}:${SPECIFIED_PORT} --env-file ${PATH_TO_ENV_FILE} ${IMAGE_NAME}:${IMAGE_TAG}
```

[Список поддерживаемых параметров конфигурации.](#configurate)

⚠️**WARNING**: при изменении порта TODO_PORT, на которм будет доступно приложение, поменяйте ${SPECIFIED_PORT} в команде запуска на это значение

### Stateful configuration

Если вы хотите запускать todo-app с сохранением стейта, пробрасывайте желауемую директорию хоста `${HOST_PATH}` внутрь контейнера с помощью флага `-v` при запуске:

```bash
docker run -p ${HOST_PORT}:7540 -v ${HOST_PATH}:/app/data ${IMAGE_NAME}:${IMAGE_TAG}
```

⚠️**WARNING**: если вы меняли расположение файла с базой с помощью переменной `TODO_DBFILE`, то измените `/app/data` на соответсвующее значение
